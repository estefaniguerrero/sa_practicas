# Sistema de Inventario

## Descripción

Este proyecto consiste en un sistema de inventario desarrollado en Python que permite registrar productos, almacenarlos en un archivo de texto, listar la información registrada y generar un reporte del IVA acumulado del inventario.

El objetivo de la práctica fue aplicar técnicas de **Código Limpio** y **Refactorización**, mejorando la organización, legibilidad y mantenibilidad del código sin modificar su funcionamiento.

---

## Funcionalidades

- Registrar productos.
- Validar la información ingresada.
- Calcular el precio final aplicando IVA y descuento para productos de tecnología.
- Almacenar los registros en un archivo de texto.
- Listar todos los productos registrados.
- Generar un reporte del IVA acumulado.

---

## Refactorizaciones realizadas

Durante el desarrollo de la práctica se realizaron las siguientes mejoras:

- Se reemplazaron nombres de variables y funciones por nombres descriptivos.
- Se eliminaron valores quemados utilizando constantes.
- Se separó la lógica en funciones con una única responsabilidad.
- Se implementó una función para calcular el precio final.
- Se creó una función para validar los datos de entrada.
- Se utilizaron comentarios para mejorar la comprensión del código.
- Se mejoró la organización general del programa.
- Se mantuvo exactamente la misma funcionalidad del sistema original.
